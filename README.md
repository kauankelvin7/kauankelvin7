# 💼 Experiência prática

O projeto de automação odontológica representa uma experiência prática de engenharia orientada a resultado.

A solução automatizou um processo operacional que:

1. Lê dados de planilhas;
2. Acessa portais das operadoras;
3. Valida guias;
4. Preenche informações clínicas;
5. Identifica e associa anexos;
6. Faz uploads automaticamente;
7. Gera logs de auditoria;
8. Produz relatórios de execução.

O resultado documentado foi a redução do tempo médio por guia de aproximadamente **8 minutos para 40 segundos**, além da eliminação dos erros de vinculação de anexos.

> **Tecnologia é meio. O resultado de negócio é o que importa.**

# 🧠 Engenharia além do código

Gosto de trabalhar em problemas que exigem mais do que simplesmente implementar funcionalidades.

Minha abordagem busca equilibrar:

| Princípio | Na prática |
|---|---|
| **Entender o problema** | Antes de escolher a tecnologia, procuro entender fluxo, usuário e regra de negócio. |
| **Código sustentável** | Prioridade para organização, legibilidade, separação de responsabilidades e manutenção. |
| **Qualidade** | Validação, testes, tratamento de erros e observabilidade quando o contexto exige. |
| **Automação** | Sempre que possível, transformo trabalho repetitivo em processo confiável e reproduzível. |
| **Performance** | Avalio custo, tempo de resposta, experiência do usuário e uso de recursos. |
| **Colaboração** | Git, branches, forks, pull requests e documentação fazem parte do desenvolvimento profissional. |
